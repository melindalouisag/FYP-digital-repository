# 📚 Digital Repository & Publication Workflow System  
### Sampoerna University – Final Year Project

---

## 📌 Overview

This project is a **web-based Digital Repository and Publication Workflow Management System** developed for Sampoerna University.

The system is designed to manage the **end-to-end lifecycle of student academic publications**, ensuring a structured, transparent, and institutionally appropriate process from submission to publication.

It integrates both:
- an **internal workflow system** (for students, lecturers, and library admins), and  
- a **public-facing repository** for accessing approved academic works  

---

## 🎯 Objectives

- Streamline the thesis and publication submission process  
- Provide clear workflow tracking for all stakeholders  
- Ensure structured academic review and validation  
- Improve transparency in approval and revision processes  
- Offer a centralized and searchable digital repository  

---

## 👥 User Roles

### 🎓 Student
- Create and manage publication registrations  
- Upload and revise submission files  
- Track progress and workflow status  
- View feedback from lecturers and admins  
- Submit clearance requirements  

---

### 👨‍🏫 Lecturer (Supervisor)
- Approve or reject student registrations  
- Review submissions  
- Provide feedback and request revisions  
- Approve and forward submissions to the library  

---

### 🏛️ Library Admin
- Review submissions after lecturer approval  
- Validate submissions using checklist templates  
- Manage clearance approval  
- Publish approved works to the repository  
- Track student progress across faculties (**NEW FEATURE**)  

---

### 🌐 Public User
- Search repository  
- View publication metadata  
- Access published academic works  
- Download files (for authenticated users)  

---

## 🔄 Workflow Overview

The system follows a structured academic workflow:

1. Registration Draft  
2. Registration Submitted  
3. Registration Approved  
4. Supervisor Review  
5. Revision Required (if applicable)  
6. Forwarded to Library  
7. Library Review  
8. Clearance Submission  
9. Clearance Approval  
10. Ready for Publication  
11. Published  

This workflow ensures proper validation at each stage before final publication.
